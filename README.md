# Dokter Ngomong Jadi Rekam Medis Otomatis

Dokter ngomong pakai Bahasa Indonesia / Jawa -> langsung jadi Rekam Medis rapi + Kode ICD-10 + Resep.

Hemat waktu dokter dari 10 menit ngetik -> 0 detik.

## Demo

Dokter ngomong:
> "Pasiene pilek, nggreges, awak e anget 3 dino, tensi 140/90, kasih paracetamol"

Langsung jadi:
> Pasien: Bu Siti | Keluhan: flu, demam | Tensi: 140/90 mmHg | ICD-10: R50.9, J00 | Resep: Paracetamol 500mg 3x1
