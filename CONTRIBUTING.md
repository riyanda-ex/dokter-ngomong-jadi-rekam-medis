# Kontribusi

Terima kasih sudah tertarik berkontribusi!

## Aturan
1. Jangan upload data pasien asli (nama, NIK, rekaman suara, foto).
2. Gunakan ID anonim: `PASIEN-001`, bukan nama asli.
3. Semua perubahan kamus Jawa harus lolos `python test.py`.
4. Satu PR untuk satu fitur / perbaikan.

## Cara
1. Fork repo ini
2. Buat branch baru: `git checkout -b tambah-kamus`
3. Jalankan test: `python test.py` - wajib 10/10 lulus
4. Buat Pull Request dengan deskripsi jelas
